## 摘要

The stochastic variational method (SVM) is one of the most powerful methods to solve quantum few-body systems precisely in various fields, such as nuclear and atomic physics. To the best of our knowledge, no SVM code optimized for GPUs has been reported. We developed a parallel SVM code for few-body clusters of $^4$He atoms and optimized it for two GPU architectures, NVIDIA GH200 and AMD Instinct MI300A, with the entire code written by an AI coding agent. On the algorithmic side, we introduce the secular-equation method with the Gu--Eisenstat prescription for solving the generalized eigenvalue problem within the SVM framework. The main part of the code tuning is to batch the many small matrices so that the GPUs are used efficiently, together with an array layout in memory optimized for coalesced addressing. For the five-body system with 4800 SVM basis states, the tuned SVM code runs 16.2 (14.7) times faster on the NVIDIA GH200 (AMD MI300A) than the same tuned code on the Intel Xeon Max CPU system, and 168 (153) times faster than the first working CPU implementation. The achieved performance brings 6-body and larger cluster systems within reach.

Abstract—The stochastic variational method (SVM) is one of the most powerful methods to solve quantum few-body systems precisely in various fields, such as nuclear and atomic physics. To the best of our knowledge, no SVM code optimized for GPUs has been reported. We developed a parallel SVM code for few-body clusters of 4He atoms and optimized it for two GPU architectures, NVIDIA GH200 and AMD Instinct MI300A, with the entire code written by an AI coding agent. On the algorithmic side, we introduce the secular-equation method with the Gu–Eisenstat prescription for solving the generalized eigenvalue problem within the SVM framework. The main part of the code tuning is to batch the many small matrices so that the GPUs are used eﬀiciently, together with an array layout in memory optimized for coalesced addressing. For the five-body system with 4800 SVM basis states, the tuned SVM code runs 16.2 (14.7) times faster on the NVIDIA GH200 (AMD MI300A) than the same tuned code on the Intel Xeon Max CPU system, and 168 (153) times faster than the first working CPU implementation. The achieved performance brings 6-body and larger cluster systems within reach. In the SVM, the wave function is written as a linear combination of correlated Gaussian basis states, which are selected stochastically from many candidates so that the variational energy is systematically lowered as the basis space is enlarged. In the original SVM the selection is performed sequentially: candidates are generated and their energies evaluated one by one, and a candidate is adopted if a certain energy gain is achieved. Such a sequential selection, however, hampers eﬀicient parallel computation, and “Parallel SVM” was proposed as a parallel-computing-based extension of the SVM [5]. In this method a fixed number of candidate basis states are evaluated in parallel, which exploits the performance of modern massively parallel computers eﬀiciently, and the best one is chosen among these candidates incrementally. In the present work, we follow this strategy which is expected to be beneficial also for GPU computing. Index Terms—Quantum many-body problem, stochastic variational method, GPU acceleration

## I. Introduction

Most of the latest supercomputers are equipped with Graphics Processing Units (GPUs), which accelerate sci- entific computations by an order of magnitude over CPU systems. Although the SVM algorithm is well suited to parallel computation, GPU programming remains a demanding task for physicists. The recent growth of AI coding agents drastically reduces this burden: performance tuning is particularly well suited to them, because the correctness of every code modification can be verified automatically against reference results and the target is clearly defined, namely the measured wall time. Quantum few-body problems, namely calculating ground-state and low-lying excited states of atomic, nu- clear, and exotic clusters, are fundamental in computa- tional physics. The Stochastic Variational Method (SVM) with a correlated Gaussian basis [1], [2] is one of the most successful methods for obtaining high-precision solutions, particularly for problems with strong correlations, such as halo nuclei or weakly bound atomic clusters like helium dimers and trimers. In the present work, we adopt the SVM to evaluate a few-body system consisting of 4He atoms. In the present work, we develop a highly tuned SVM code employing AI-coding and discuss its performance on GPU machines. This paper is organized as follows: the present Hamiltonian and the framework of the SVM are described in Sect. II, Sect. III is devoted to the algorithm and code improvements, and the energy convergence and the code performance are discussed in Sect. IV. Sect. V summarizes this work. The helium-4 cluster system has attracted much interest in connection with the Efimov physics. Solving the generalized eigenvalue problem with the secular equation At each SVM step, a (K + 1)-dimensional generalized eigenvalue problem must be solved for each of the Nt can- didates. Solving it from scratch costs O(K3), so that this stage alone would cost O(NtK3) per step and O(NtN 4 b ) for the whole run, which overtakes the cost of the matrix elements as soon as Nb becomes large, even though its eﬀicient GPU implementation is feasible [10]. The eigenvectors are needed only once per step, for the candidate that is actually accepted, because the (K + 1)- th step requires all the eigenpairs of the K × K problem. They are constructed from the roots of Eq. (16) by the Gu–Eisenstat prescription [11]: building the eigenvectors directly from the βk loses their orthogonality when two roots lie close to each other, and the prescription instead reconstructs the couplings from the computed roots, which restores orthogonality to working accuracy. The cost of this update is O(K3), but it is dominated by a single matrix–matrix product, the back transformation of the eigenvectors into the original basis, which runs far faster than a general eigenvalue solver such as dsygvd. ## V. Summary

We presented the algorithm and code developments of the SVM for the five-body 4He atomic system. The present code was highly tuned with the aid of AI coding. Employing the secular equation for low-lying eigenvalues significantly accelerates the SVM computation and makes a large number of basis states feasible, which is directly relevant to the capability of the SVM. We achieved a 168- fold acceleration on the GH200 over the baseline CPU code, and a 16-fold acceleration over the tuned CPU code. The loop exchange, which enables the eﬀicient use of SIMD on CPUs and of coalesced addressing on GPUs, has a significant impact. This code makes 6-body calculations and beyond computationally feasible.
